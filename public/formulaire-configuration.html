Configuration de mon groupe

Remplissez ce formulaire (5 minutes) : nous configurons votre groupe pour vous. Vous gardez le contrôle : c'est vous qui validez notre accès dans l'application.

1Votre groupe

2Le responsable du groupe (facultatif)

S'il y en a un, c'est lui qui validera notre accès dans l'application et qui recevra son compte. Sans responsable, nous configurons directement le groupe.

3La saison

4Les membres

Ajoutez-les un par un, ou collez votre liste (une personne par ligne : Nom Prénom ; téléphone ; poste ; e-mail). Un compte My2-0 est créé pour chaque membre : l'e-mail est facultatif.

5Les cotisations

Cotisation mensuelle, adhésion, fonds de caisse… (facultatif)

6Les sanctions

Les amendes de votre règlement intérieur (facultatif).

7Vos matchs

8Votre accord

Vos informations restent sur votre téléphone tant que vous ne les envoyez pas : ce formulaire ne les enregistre sur aucun serveur. Les numéros de téléphone des membres ne sont utilisés que pour créer leur fiche.
